# GitHub Copilot native distribution 0.66.0

The complete contained profile is [the immutable full payload](https://github.com/Shaisolaris/solaris-dev-shop-plugins/tree/023f610ef085101c1bb01f2ec0760390af12c4f1/copilot/plugin): 61 specialists, one coordinator, 1,200 canonical hashes and 1,979 files/modes. Workflows are selected on demand; this layout adds no setup hook, background service, updater or account grant.

The golden rebuild exercises 62 helper contexts, actual coordinator assignment, SQLite restore/neighbor preservation, helper escape/tampering refusal and rejection of unfinished input. Source CI remains inert and notices are applied once. Host permissions and runtime prerequisites apply; these source checks are separate from model quality and provider approval.

The original full-product request [#5257](https://github.com/github/awesome-copilot/issues/5257) was rejected for scope/style/complexity; Docker was not the stated reason. The separate companion request [#5390](https://github.com/github/awesome-copilot/issues/5390) was withdrawn after the owner chose one complete product. Substantive full-product reconsideration requires the exact reviewed new revision and a maintainer decision. No directory approval is implied here. See [validation](VALIDATION.md).
