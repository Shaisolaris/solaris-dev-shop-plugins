# Solaris Dev Shop for Google Antigravity

The native Antigravity profile is `harnesses/antigravity`:61 specialist workflows plus one chief-of-staff coordinator, with complete contained Python helpers and resources. It follows Google's documented `plugin.json` format, using only `name` and `description`. It adds no hooks, rules, subagents, MCP servers, credentials, background work or permission grants. It does not reuse another provider's incompatible manifest.

The full profile preserves1196 canonical files at core `ee38d3de3d4b0d5467a589d5cb908f4964f593fe` and native source `085ebb9e9c137c5046c2153b9413d9badd102ce7`. Golden rebuild, all62 installed-layout context calls and a live coordinator assignment pass; unknown manifest properties are rejected by the schema embedded in Google's official plugin documentation. The advertised hosted schema URL returned404, so this is a local documented-schema check rather than a hosted Google validation.

Antigravity CLI1.4.5 was downloaded from Google's official release manifest with SHA512 verified. Its help command works. Its plugin manager initializes the real Google profile before handling plugin commands, and a protected test refusing access to that real profile stopped at directory initialization. Native installation/activation is therefore **not verified** in an isolated profile, and no existing Google profile, credential or retired worker was modified or started. Marketplace submission requests compatibility review and makes no runtime-approval claim.

Google supports a custom plugin folder under `.agents/plugins/` in an assigned workspace, a GitHub-root plugin, or the official marketplace after vendor acceptance. Install the complete profile, not individual skill directories. Python helpers require Python3.10+; individual prerequisites and host approvals apply. This distribution adds zero new employee capabilities.
