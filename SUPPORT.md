# Support

Publisher: Solaris Technologies. Business contact: shehryar@solaristek.com.

Use this repository's issues for native plugin installation, discovery and
packaging defects. Include the host and version, distribution commit, command,
expected behavior and a short redacted error. The implementation source and
capability guide are linked in README.md.

Do not post credentials, private source code, personal data or customer records
in public issues. Send sensitive security details to the business contact rather
than a public issue. Do not attach unredacted host catalogs or account logs.

Workflows require appropriate host tools and permissions. A missing local runtime,
provider login or native environment is a real prerequisite; installation does not
grant it. Curated marketplace approval is separate from this source distribution.
