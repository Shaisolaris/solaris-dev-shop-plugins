# Solaris Dev Shop for Cline

61 specialists plus a chief-of-staff coordinator: 62 workflows. Complete reviewed source and local helpers are retained; this distribution adds zero core employee capabilities. Install the complete directory plugin, not its skills alone.

The Cline package manifest declares its SDK entrypoint; Cline discovers the top-level bundled skills. A real solaris_intake tool routes a request through the pinned Python coordinator and returns an assignment. It does not run specialist work. It accepts one nonempty UTF-8 request up to 32KiB, uses execFile with no shell, a 20second timeout and a minimal child environment. No lifecycle hooks, model/provider changes, grants, MCP, network calls or background jobs.

Local helpers need Python3.10+ and PyYAML on the host PATH. Individual specialists retain their documented prerequisites and permissions. Amp hosted/Puck and Cline VS Code/JetBrains support are separate client gates, not established by native CLI/SDK discovery.
