# Solaris Dev Shop for Pi

A native Pi package of 61 specialist workflows and the chief-of-staff coordinator, version0.63.0. It reuses the existing complete contained profile; this manifest adds zero employee capabilities.

```sh
pi install git:github.com/Shaisolaris/solaris-dev-shop-plugins@<full-reviewed-commit>
```

For local authoring, use `pi install ./path/to/checkout`. The package declares 62 exact skill file paths and no extension code, prompt templates or themes. Its complete shared Python runtime stays under `copilot/plugin`; installing individual skill folders would omit that runtime.

Pi1.4.0's actual local package manager and public SDK resource/skill loaders resolve 62 unique names with no diagnostics. Public Git installation and registry publication are recorded separately. No model call was made. The host provides tools and approvals; Python helpers need Python3.10 or later. This is not a security sandbox or a claim that all61roles gained new executable behavior. See [the harness distribution evidence](HARNESS-DISTRIBUTION.md).
